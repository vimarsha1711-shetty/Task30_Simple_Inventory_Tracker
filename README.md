Task 30: Simple Inventory Tracker

Objective

Create an Excel sheet that tracks current stock, reorder levels, and stock status using rule-based formulas.

Tools

• Microsoft Excel
• IF formulas
• Conditional formatting

Workbook sheets

1. Inventory Tracker — sample inventory with stock status and recommended action.
2. Low-Stock Report — formula-driven list of items that need reordering.
3. Summary — key counts and instructions.

Rules used

• If Current Stock is less than or equal to Reorder Level, the status is REORDER.
• Otherwise, the status is IN STOCK.
• The recommended action suggests ordering the specified reorder quantity for low-stock items.
• Low-stock statuses are highlighted in red; in-stock statuses are highlighted in green.

Dataset note

This project uses a clearly labelled, illustrative sample dataset created for this task because no dataset file was attached to the task screenshot. Replace the sample rows with real inventory data if your internship portal provides a specific dataset.

How to use

1. Open Task30_Simple_Inventory_Tracker.xlsx.
2. Edit the Current Stock and Reorder Level columns.
3. Review the automatic Stock Status and Recommended Action fields.
4. Check the Low-Stock Report sheet for items that need reordering.
5. Save the workbook before uploading it to GitHub.

Interview questions

What is a reorder level?
It is the minimum stock threshold that signals when an item should be reordered.

Why track stock status?
It helps prevent stockouts, supports timely purchasing, and makes inventory easier to monitor.
